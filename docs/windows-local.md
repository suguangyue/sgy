# Windows 单机运行说明（方案草案）

当前仓库尚无可运行程序。本说明描述目标运行方式，具体框架和打包命令将在源代码实现后补充。

## 目标体验

- 支持 Windows 10/11 64 位；先以单机、单用户为目标。
- 首选本地桌面界面 + SQLite 数据库；Python 桌面应用和 EXE 打包是候选路径，需在原型阶段验证依赖、启动速度、升级与杀毒软件误报情况。
- 首次启动可选择数据目录并创建数据库；后续启动自动打开最近使用的数据。
- 软件和用户数据分开存放。卸载/升级不应默认删除数据库。
- 不要求网络连接即可完成日常录入、查询、对账和报表导出。

## 本地数据与备份

1. 数据库保存在用户可访问的本地数据目录，而不是程序安装目录。
2. 提供“立即备份”功能，复制前确保数据库处于一致状态；备份文件带时间戳。
3. 提供恢复前确认与目标文件检查；恢复操作前自动留一份当前库副本。
4. 建议用户定期将备份复制到另一块可靠存储介质。EXE 不是数据备份。
5. 在日志和错误报告中避免写入敏感字段或整个导入表格。

## 运行与发布验收

- 开发模式运行和打包后运行都能打开、创建、升级数据库。
- 在无开发环境的干净 Windows 机器上启动 EXE、导入模板、保存数据、重启后数据仍在。
- 路径含中文/空格、无管理员权限、磁盘空间不足等场景有清楚提示。
- 数据库迁移前自动备份；失败时保留原始数据库并提示恢复方法。
- Windows EXE 仅在验证恢复、导入回滚和对账结果后发布。发布版本应标注版本号及构建日期。
