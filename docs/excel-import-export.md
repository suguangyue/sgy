# Excel 导入导出设计

## 导入流程

1. **选择文件与类型**：支持约定模板的 `.xlsx`，首阶段按学员、缴费/套餐、收支等业务类型分别导入。
2. **读取与映射**：识别工作表和表头；显示系统字段与源列映射。未知列保留提示，不静默丢弃。
3. **预览与校验**：显示行数、通过数、错误数、警告数及逐行原因。校验必填值、日期、金额、枚举和关联对象。
4. **重复检测**：优先使用外部编号/稳定业务键；无稳定键时标记疑似重复供人工判断，不能只按姓名合并。
5. **确认导入**：预览后由用户确认。一个批次在事务中写入，整批成功或回滚；导入批次记录文件名、时间、行数和结果，不保存不必要的原始敏感内容。
6. **结果报告**：给出新增、更新（若允许）、跳过及失败数量，可下载错误行报告。重复执行同一批次应能检测并避免重复记账。

## 财务安全约束

- 缴费、退款与收支默认只新增；已入账金额的修改/撤销需走更正或冲销并记录原因。
- 禁止导入过程自动猜测并覆盖正式账目。
- 导入金额统一按明确格式解析并转换成分；拒绝模糊日期、非法金额、负数或超出规则的退款。
- 对应学员/课程/报名找不到时标记为待处理，不自动创建错配关系。
- 正式导入前可导出当前数据备份；大批量导入显示数量和影响范围。

## 导出设计

- 按业务模块和日期范围导出为 `.xlsx`，至少提供学员缴费明细、课次核销、退款、经营收支和期间对账报表。
- 报表包含生成时间、筛选条件、金额单位和汇总口径；明细可回溯到内部业务编号。
- 导出只包含用户所选范围和字段；手机号、备注等敏感信息默认不纳入财务报表。
- 防止 Excel 公式注入：将用户输入的文本按纯文本处理，避免以 `=`、`+`、`-`、`@` 起始的内容被当作公式执行。
- 导出汇总与系统内同一筛选条件的金额合计一致；导出不改变数据库数据。

## 模板与兼容性

- 提供带版本号的空白模板和字段说明；模板中不得放入真实学员数据。
- 初期约定列名与日期、金额格式；模板变更时更新版本并尽量兼容旧模板。
- 在常用 Excel 与 WPS 表格中验证中文、日期、金额精度、长编号和空值显示。
