# 悦弈围棋财务管理系统

面向悦弈围棋线下校区的 Windows 单机财务与经营管理工具。项目从文档基线开始，逐步实现真实业务数据导入、学费与收支对账、Excel 导入导出、经营看板，并最终打包为 Windows EXE。

> 当前仓库是项目文档骨架，不含应用程序代码、可执行文件或真实业务数据。数据模型与技术路径均为待验证草案。

## 目标

- 在一台 Windows 电脑上本地运行，不依赖云端服务。
- 管理学员、课程/套餐、缴费、课次核销、退款及日常收支。
- 能从现有表格导入数据，并在导入前预览、校验、处理重复记录。
- 提供可追溯的对账结果与 Excel 报表。
- 数据默认保存在本机，提供清晰的备份与恢复方式。
- 后续构建独立安装或免安装 EXE 版本。

## 建议实施阶段

1. 确认字段、现有表格格式及财务口径。
2. 实现本地数据库、基础档案和导入预览。
3. 实现缴费、核销、退款、收支记录与对账。
4. 实现 Excel 导出、备份恢复及经营看板。
5. 在干净的 Windows 环境验证并打包、签出 EXE。

## 安全与数据约定

- 不要向公开仓库提交学员姓名、联系方式、缴费记录、身份证件、银行信息、数据库、备份或导入源文件。
- 本仓库只存放源代码、文档和不含真实个人信息的测试样例。
- 涉及删除、覆盖或批量导入时，应用应先预览并要求明确确认；重要财务记录通过冲销/更正留痕，不静默抹除。
